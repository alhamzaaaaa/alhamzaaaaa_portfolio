# Portfolio foundation

This archive establishes the initial App Router foundation for the portfolio.

- `src/app`: routes, root layout, global CSS.
- `src/components`: shared layout, UI, section, and React Bits components.
- `src/backgrounds`: centralized background selection configuration.
- `src/data`: portfolio content data.
- `src/lib`: shared utilities.

The application uses JavaScript throughout. TypeScript source files and TypeScript-specific project configuration have been removed.

The `@/*` alias points to `src/*`.

After extracting this archive over the project, run `npm install`, then `npm run dev` and verify the page.
